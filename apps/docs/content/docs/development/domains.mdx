---
title: Domain Reference
description: Capability owners, public contracts, and non-obvious boundaries.
---

| Capability | Owner and contract | Boundary |
| --- | --- | --- |
| Commands, shortcuts, clipboard and input arbitration | [`actions`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/actions/public.ts) | Owns action IDs, eligibility, and input adapters; delegates content changes through Canvas commands |
| Editable content, Yjs projection, history and viewport | [`canvas`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/canvas/public.ts) | Owns active Yjs content, projection, and history; [state flows](/development/architecture/state-flows) owns origin and persistence direction |
| Character catalog, packs, facets and filters | [`character-library`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/character-library/public.ts) | Generated datasets are inputs; insertion belongs at the widget/canvas boundary |
| Room links, connection lifecycle and presence | [`collaboration`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/collaboration/public.ts) | Owns room transport, room-local persistence, and presence; Canvas owns editable maps, projection, and integrity filtering |
| External text parsing and conversion | [`document`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/document/public.ts) | Owns session-source conversion and the [pluggable pasted-text renderer](/development/architecture/text-rendering); Canvas applies results without owning syntax rules |
| Runtime, commands, tools, keymaps and extensions | [`editor`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/editor/public.ts) | Coordinates execution; owns neither canvas data nor product metadata |
| Export registry, preparation and browser delivery | [`export`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/export/public.ts) | Pure preparation returns a delivery-neutral result before platform side effects |
| Static-grid addresses, ranges and movement | [`selection`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/selection/public.ts) | Deterministic and independent of React, DOM events and browser coordinates |
| Session identity, catalog schema and migrations | [`sessions`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/sessions/public.ts) | Owns IndexedDB catalog records and legacy decoding; Canvas owns Yjs document persistence coordination and runtime recovery |
| Deck, slide mutation, dimensions and Markdown | [`slides`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/slides/public.ts) | Owns pure deck rules and Markdown; Canvas owns the active editing buffer, projection, and crop/history coordination |
| Structured nodes, geometry, layout and scene rendering | [`structured-content`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/structured-content/public.ts) | Model operations stay UI-independent; canvas applies a scene as one semantic mutation |

Use the selected `public.ts` and nearest tests. Dependency rules are owned by
[ownership and dependency direction](/development/architecture/ownership).
