`.ans` retains ESC for terminals. `.chardesk` is the visible ESC-less profile:
its bytes are the editable visual product, and Structured exports intentionally
return as Freeform.
[`parseDocumentSessionSource`](https://github.com/Sayhi-bzb/CharDesk/blob/main/src/domains/document/session-source.ts)
is the import discriminator: a BOM-stripped string beginning with `---` routes to Slides Markdown;
other text routes to the Canvas adapter.

Change vendored fonts and generated Unicode width data through
[`vendor-fonts.mjs`](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/fonts/vendor-fonts.mjs)
and [`generate-character-data.mjs`](https://github.com/Sayhi-bzb/CharDesk/blob/main/scripts/data/generate-character-data.mjs),
not their checked-in output. The root [`package.json`](https://github.com/Sayhi-bzb/CharDesk/blob/main/package.json)
owns the commands.
